# FAST-NUCES Transport Management System

This repository contains a Python and Tkinter desktop application for managing university transport operations.

The application source is in [python_transport](python_transport/). See its [README](python_transport/README.md) for setup, portal capabilities, semester-based storage, and the custom data structures and algorithms used in the project.

## Run

```powershell
cd python_transport
python app.py
```

The app creates `transport_data.json` beside its source files when it saves data. The default administrator password is `admin123`.
